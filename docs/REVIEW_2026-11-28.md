Scope: everything in `C:\Oracle\plugin-host` at commit `86312d1`. Nothing has been compiled or run. The goal now is to make the
code as correct as possible by reading, then hand it to a Linux host.

Method: six independent reviews (architecture and plan, static C++ check against LibreOffice and QuickJS sources, Linux web

administrator pre-approval, UNCLASSIFIED API rows count as edit, pilot = the ten shim methods.

Severity: **S1** blocks the pilot or crashes LibreOffice. **S2** wrong result, security hole or large performance loss. **S3** cleanup.

## 2. Worst, ordered by impact

| # | Sev | Finding | Status |
|---|---|---|---|
| 2.1 | S1 | **Linux web view cannot embed under the default gtk3 VCL plugin.** UNO gives only a display pointer and a window id (`vclxsystemdependentwindow.cxx:77-83`). With gtk3 that id belongs to a GDK window of this process, so `gtk_plug_new` cannot embed. Native Wayland gives a `wl_surface*`, not an XID. Works only with the kf5/qt5 plugin on X11. WebKitGTK stays; the embedding method does not. | **Partly verified** (the UNO side). Needs the Linux spike. Decision needed (section 8). |
| 2.2 | S1 | **Every bridge call fails.** `opCall` looks the method up with `getType(Any(obj))`, which returns the class of the Any's static type `XInterface` (`stoc/.../crefl.cxx:89`: `forType(rObj.getValueTypeRef())`). Only `queryInterface/acquire/release` are found. Fix: `forName(iface)->getMethod(name)`, cached per `iface.method`. | **Verified.** Fix in progress. |
| 2.3 | S1 | **Interface arguments are passed with the wrong vtable.** `Any(&ref, type)` copies the pointer without `queryInterface`. Two of the ten pilot calls hit this. Fix: `ref->queryInterface(type)` and check the result. | **Reported.** Fix in progress. |
| 2.4 | S1 | **`setDataArray` cannot work.** The element type `any` is refused, but `ApiRange.SetValue` needs it. Decision 9 ("refuse Any until a pilot member needs it") is now met. | **Reported.** Fix in progress. |
| 2.5 | S1 | **UNO exceptions crash LibreOffice.** `jsPhCall` and `handleExecuteMethod` catch only `std::exception`; UNO exceptions unwind through QuickJS and GLib C frames and end in `std::terminate`. One bad `GetRange("x")` kills the office. | **Reported.** Fix in progress. |
| 2.6 | S1 | **The TestRunner cannot test anything.** Component context is never set without a panel; the `__test__` id has no permissions so the bridge refuses every call; the root comes from `getCurrentComponent` (unreliable headless); remote calls arrive on a worker thread, which breaks QuickJS's stack check; nothing installs the extension into the runner's private profile. | **Reported.** Fix in progress. |
| 2.7 | S2 | **Locale-dependent numbers.** GTK sets the user's locale (decimal comma). `strtod` reads `1.5` as 1; `snprintf("%.17g")` prints `1,5`, which is invalid JSON. NaN prints as a bare token. | **Reported.** Fix in progress. |
| 2.8 | S2 | **`calculateAll()` after every command**, ignoring the page's `isCalc` flag: seconds on a large workbook. Use `calculate()` and only when needed. | **Reported.** Fix in progress. |
| 2.9 | S2 | **Property get/set bypass the allowlist.** Any identifier-shaped property is readable and writable (for example Calc `IsUndoEnabled = false` defeats the Undo guarantee). Fix: refuse all properties until a property allowlist exists. | **Reported.** Fix in progress. |
| 2.10 | S2 | **The denylist blocks `createInstance` on the document**, which tables, shapes and images need. Large parts of the API are unreachable. Needs a design: allow it on the document root with a service-name allowlist. | Deferred until after the pilot. |
| 2.11 | S2 | **Permission policy contradicts itself.** ADR-002: option A, no prompt. DECISION_LOG round 2: "first-use prompt is the only approval path". Code: only `hostPermissions`. | Wording reconciled (A stands); **needs the user's confirmation** (section 8). Code fix planned. |
| 2.12 | S2 | Sessions keyed by plugin id only; a second document's panel steals the view; commands target `getCurrentComponent`. Bind to the panel's frame. | Planned (step 11). |
| 2.13 | S2 | `__ph_call` is still a global with no permission check. | Removed with the shim after the pilot. |
| 2.14 | S3 | Smaller: static `qjs` needs `-fPIC`; no `-fvisibility=hidden`; WebKitGTK linked into the main library (a missing library breaks the whole component); stale `Asc.bridge` reuse across commands; no handle cap; `fileUrl` without percent-encoding; third-party iframes can message the host; two environment variables still honoured in release builds. | Mostly fixed in this round; the rest planned. |

## 5. Performance risks

| Risk | Estimate | Mitigation |
|---|---|---|
| `GetElement(i)` re-enumerates from the start | O(n^2); about 4.5 M calls for 300 pages, minutes (budget 50 ms) | One native `enumerate(handle)` operation plus a per-command element cache |
| One JSON round trip per UNO call | about 5-30 microseconds per call (unmeasured) | Microbenchmark first, then direct JSValue conversion |
| Method lookup scans `getMethods()` per call | O(methods) per call | `forName` plus a per-`iface.method` cache (part of 2.2) |
| `calculateAll()` after every command | seconds on a large workbook | `calculate()` only when needed (2.8) |
| No cap on live handles | memory grows in loops | Cap at 100,000 |
| One WebKit context per plugin | one web process each | Accept for internal use; measure |
